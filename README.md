## 三、本次实录的核心观点速览

如果你只想快速了解**梁文锋四小时投资人会议实录**中谈了什么，以下是要点摘录：

### 1. 愿景与开源
- DeepSeek 是"愿景驱动"而非"KPI 驱动"的组织，愿景甚至没有成文。
- **坚持开源**并非让利，而是 AI 足够大、一人独占不可能做成的客观规律。
- API 定价逻辑：**十个月收回设备成本**，对应约 **6 倍利润**；继续降价需求无弹性，无意义。

### 2. AGI 技术路线
- AI 智能发展是阶梯式的：**语言模型 → CoT（思维链） → Agent → 持续学习 → 自我迭代奇点 → 具身智能**。
- 下一个关键瓶颈是**持续学习（Continuous Learning）**，也是全球学术界尚未解决的问题。
- 多模态、搜索都只是"组件"，不是智能主线本身。

### 3. 算力与国产芯片
- DeepSeek 当前算力约 **2 万张 H 等效**；与美国的最大差距是**资源**（卡），不是人才。
- 国产芯片有**历史性机遇**：AI + 高级编译器（如自研 **TileLang**）正在快速瓦解英伟达 CUDA 护城河。
- 华为 950 超节点可平替英伟达 GB200/GB300，差距约为"**四张顶一张 + 落后两年**"。

### 4. 组织管理与商业化
- 公司**唯一的核⼼利益是团队稳定性**——只要团队不散，AGI 一定能做成。
- 决策机制建立在**共识**之上，而非个人权威。
- C 端和 B 端业务都被视为 AGI 主线上的"副产物"，不做垂直整合、不造芯片、不做金融医疗等纵向应用。

### 5. 投资人 Q&A 精选
- AGI 一两年内国内能追上国外模型；国产硬件追上需要几年，主要瓶颈是**生态 + 产能**。
- 下代模型目标激活参数 **150B–250B**；对标 OpenAI o 系列更前沿版本。
- 资本市场与纯科研的平衡：明年 B 端收入放量后，公司有望接近净利润，"最坏情况下只卖 API 也够支撑一家上市公司"。
